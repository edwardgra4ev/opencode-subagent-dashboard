# Сабагенты для OpenCode Desktop

Плагин боковой панели OpenCode Desktop 2: показывает сабагентов текущей сессии деревом — кто
сейчас работает, чем занят и сколько уже потратил.

В строке: точка статуса, имя агента, заголовок сессии, четыре корзины токенов
(`↑ вход`, `↓ выход`, `R кеш чтение`, `W кеш запись`), их сумма, цена и затраченное время.
Клик по строке раскрывает деталь прямо в панели; кнопка у правого края строки открывает чат
сабагента в новой вкладке. Пока сабагенты работают, в заголовке вкладки панели видно их число.

English: [README.md](README.md).

## Требования

- OpenCode Desktop 2.3.x. GUI-API плагинов экспериментальный и может меняться между
  релизами.
- Node.js 20+ — только если собираете плагин сами; в репозитории уже лежит собранный
  `dist/gui-experimental.cjs`.
- Плагин собран под `@opencode/plugin` 2.3.2, версия закреплена в `package.json`.

## Установка из git (рекомендуется)

```bash
git clone https://github.com/edwardgra4ev/opencode-subagent-dashboard \
  ~/.config/opencode/plugins/subagent-dashboard
```

Добавьте плагин в `~/.config/opencode/opencode.json`:

```json
{
  "plugins": ["./plugins/subagent-dashboard"]
}
```

Один раз перезапустите OpenCode Desktop. Панель появится в меню `+` боковой области, в
палитре команд и по `/agents`.

`dist/gui-experimental.cjs` лежит в репозитории, поэтому после клонирования собирать ничего
не нужно. Обновление:

```bash
git -C ~/.config/opencode/plugins/subagent-dashboard pull
```

Затем перезапустите Desktop (или перезагрузите плагины в приложении).

## Установка из архива релиза

К каждому тегу прикладывается `opencode-subagent-dashboard-vX.Y.Z.zip`: исходники `src`,
собранный `dist`, документация и файлы сборки (`package.json`, lock-файл, `vite.config.ts`,
`tsconfig.json`). Внутри нет `node_modules` и истории git, поэтому для установки Node.js не
нужен:

```bash
mkdir -p ~/.config/opencode/plugins/subagent-dashboard
unzip opencode-subagent-dashboard-v0.1.0.zip \
  -d ~/.config/opencode/plugins/subagent-dashboard
```

Дальше укажите `./plugins/subagent-dashboard` в `plugins`, как при установке из git, и
перезапустите Desktop.

## Установка из другого каталога

Плагин грузится из любого каталога — укажите его путь в `plugins` (абсолютный или
относительно каталога конфигурации):

```json
{
  "plugins": ["/mnt/hdd/Dev/opencode-plugins/opencode-subagent-dashboard"]
}
```

## Как открыть панель

- Меню `+` боковой области, затем **Сабагенты**.
- Палитра команд, **Открыть сабагентов**.
- `/agents` в поле ввода. Без открытой сессии команда недоступна.
- Горячая клавиша: пункт меню `+` показывает сочетание команды `subagent-dashboard.open`.
  По умолчанию сочетания нет — назначьте его этой команде в Settings › Shortcuts.

## Что показывает панель

Панель перечисляет сабагентов сессии в текущей вкладке, а не всех сессий приложения.

**Панель остаётся открытой.** Откройте её один раз — из меню `+`, палитры или по `/agents` — и
она закрепляется: в каждой следующей сессии панель снова на месте. Закрытие вкладки панели
снимает закрепление. Desktop хранит вкладки панелей отдельно для каждой сессии, поэтому плагин
переоткрывает свою панель при переключении; после перезапуска Desktop панель тоже открывается
сама, если была открыта при выходе.

**Дерево.** Строки группируются по `parentID` и сдвигаются по глубине, поэтому дети всегда
стоят под своим родителем. Если у строки на последнем уровне (3) есть свои дети, они
сворачиваются в некликабельную строку-маркер `…`.

**Порядок.** Внутри уровня сначала идут выполняющиеся строки, остальные — по времени создания,
новые сверху. Дети всегда стоят сразу под родителем, так что дерево читается сверху вниз.
Сабагент, о котором известно только из списка `background` сессии и которого ещё нет в сторе
сессий, показывается первым как выполняющийся, курсивом, пока не синхронизирован.

**Строка.** Точка статуса, агент, заголовок, а справа — четыре корзины токенов: `↑` вход,
`↓` выход, `R` кеш чтение, `W` кеш запись, затем их сумма, цена и затраченное время. Заголовок
обрезается до одной строки, полный текст виден по наведению. Статусы и цвет точки:

| Статус | Точка | Значение |
| --- | --- | --- |
| Выполняется | синяя | Ещё работает, надо подождать |
| Завершён успешно | зелёная | Закончил нормально |
| Ошибка | красная | Закончил с ошибкой |
| Прерван | оранжевая | Остановлен до завершения |
| Простаивает | серая | Известен, но не запущен или не работает |

Точка выполняющейся строки пульсирует; при `prefers-reduced-motion: reduce` анимация
отключается.

**Пустой расход.** У ещё выполняющегося сабагента, от которого не пришло ни одного события
расхода, вместо корзин, суммы, цены и времени стоит один `—`, а не нули. Суммы показываются как
`812`, `12.3k`, `1.2M`; итог — `вход + выход + чтение + запись`; цена меньше цента — `<$0.01`.

**Время.** У выполняющейся строки — от старта прогона (`time.busy`) до сейчас, обновляется раз
в секунду. У завершённой — длительность прогона, `idle − busy`. Если нужной отметки нет, `—`.

**Клик по строке.** Строка раскрывает деталь сабагента внутри панели; повторный клик по ней
возвращает список (см. ниже). Кнопка-стрелка у правого края строки с подсказкой **Открыть чат**
открывает сессию этого сабагента в новой вкладке. Строки сессий, которых больше нет (`missing`,
например после удаления), приглушены и отключены, так что недоступны оба действия.

**Деталь.** Деталь заменяет список: строка агента остаётся закреплённой сверху, под ней две
вкладки — **Вход** и **Выход**. **Вход** — задача, которую дали сабагенту: первое сообщение
пользователя с текстом. **Выход** — последний текст, который написал его ассистент. Оба
отрисовываются markdown-рендерером Desktop: заголовки, списки, таблицы, код с подсветкой и
кнопкой копирования, ссылки. Рассуждения и вызовы инструментов не показываются. Вывод занимает
оставшуюся высоту панели и прокручивается внутри неё; футер остаётся на месте. Вкладки
переключаются мышью или клавишами `←`/`→`, `Home` и `End` ведут на «Вход» и «Выход». Деталь
всегда открывается на «Выходе», одновременно открыта только одна деталь, а раскрытие другой
строки заменяет её.

Содержимое подгружается при первом раскрытии детали: до этого `Загрузка вывода…`. Пустой
«Выход» показывает `Вывода пока нет`; «Вход» — `Промпт не сохранён`, когда история сессии
загружена полностью. Старые сообщения подгружаются при первом открытии «Входа», поэтому там
может быть `Загрузка вывода…`, пока промпт ещё не найден. Если загрузка не удалась, вкладка
показывает `Не удалось загрузить вывод: …`, а клик по «Входу» повторяет попытку.

**Фильтр.** **Только активные** скрывает завершённых сабагентов и группу завершённых. Он
появляется, когда в сессии есть сабагенты.

**Группа завершённых.** Завершённые сабагенты лежат под заголовком `N завершено`, который
сворачивается кликом. По умолчанию группа раскрыта, если завершённых не больше 5, иначе
свёрнута.

**Длинные списки.** Одновременно рисуется не больше 200 строк; кнопка `+N ещё` показывает
остальные.

**Состояния.** `Сабагентов нет`, пока в сессии их нет; `Загрузка…`, пока идёт первая
синхронизация; `Нет активных сабагентов`, если фильтр ничего не оставил; тост, если
синхронизация не удалась.

**Футер.** `3 сабагентов · ↑ вход 4.2k · ↓ выход 812 · R 80k · W 11.4k · всего 96.4k · $0.12`
по всем сабагентам сессии, включая скрытых фильтром, свёрнутой группой и лимитом строк.

**Уведомления.** Когда сабагент завершается, а ни одно окно приложения не в фокусе, приходит
системное уведомление: ошибки — как ошибки, остальные — как обычное завершение. Клик по
уведомлению открывает сессию этого сабагента. Уведомления подчиняются настройкам OpenCode
(Settings › Notifications: Agent и Errors, а также их звуки) и приходят не чаще одного раза на
завершение.

**Данные.** Всё берётся из стора сессий Desktop и его событий; собственного доступа к базе у
панели нет. При переходе на сессию её дети загружаются один раз, дальше статус, токены и
таймеры обновляются по событиям.

**Состояние панели.** Фильтр, группа завершённых, `+N ещё`, открытая деталь и позиция прокрутки
списка хранятся отдельно для каждой сессии. Уход с вкладки панели или переключение на другую
сессию и обратно возвращает то, что вы смотрели; закрытие вкладки панели стирает состояние этой
сессии.

## Ограничения и заметки

- Показываются только сабагенты текущей сессии; сессии других вкладок — нет.
- Глубина дерева ограничена 3 уровнями; более глубокие сабагенты видны как `…`.
- До 200 строк рисуется сразу, остальные — по кнопке `+N ещё`.
- На вкладке «Выход» только последний текстовый ответ: рассуждения, вызовы инструментов и
  прошлые ходы не показываются. На вкладке «Вход» только первое сообщение пользователя;
  последующие уточняющие сообщения в него не входят.
- Строка `missing` приглушена и отключена, её деталь не открыть.
- Одновременно открыта одна деталь. Каждая сессия помнит свою открытую деталь и позицию
  списка, но деталь всегда открывается на вкладке «Выход».
- Плагин рассчитан на OpenCode Desktop 2.3.x и экспериментальный GUI-API плагинов; обновление
  Desktop может сломать панель до обновления плагина.
- Время выполняющейся строки всегда считается от `time.busy`: у возобновлённой сессии
  остаётся старый `time.idle`, и таймер по нему замер бы.

## Темы

Панель оформлена только переменными приложения `--v2-*`, поэтому светлая и тёмная темы,
включая свои, наследуются от Desktop.

## Разработка

```bash
npm install
npm run typecheck
npm run build     # пишет dist/gui-experimental.cjs, файл лежит в репозитории
npm run watch     # пересборка при изменении; панель перезагружается во всех окнах
```

`dist/` хранится в репозитории, чтобы обычный `git clone` не требовал сборки. Меняя `src/`,
пересоберите и закоммитьте `dist/gui-experimental.cjs` вместе с исходниками.

Структура:

| Путь | Назначение |
| --- | --- |
| `src/index.ts` | серверная половина: `Plugin.define({ id: "subagent-dashboard" })`, без обработчиков |
| `src/gui.tsx` | вход GUI: панель, закрепление между сессиями, пункт меню `+`, команда `/agents`, счётчик выполняющихся в заголовке вкладки, уведомления о завершении, стили |
| `src/gui/dashboard.tsx` | сама панель: строки, кнопка чата, деталь с вкладками «Вход»/«Выход», фильтр, группа завершённых, лимит строк, футер, состояние вида по сессиям |
| `src/gui/model.ts` | чистая модель: дерево, порядок, слияние с `background`, `lastAssistantText`, `userPromptText`, форматтеры |
| `src/gui/definition.ts` | декларация плагина со словарями en/ru |
| `src/gui/i18n.ts` | тексты на английском и русском |

Раскрытие детали синхронизирует сообщения этой сессии (`message.sync`), поэтому сессия,
открытая рядом в чате, может перечитать своё окно сообщений. Загрузка вкладки «Вход» так же
подтягивает старые сообщения сессии.

### Непрерывная интеграция

`.github/workflows/ci.yml` запускается на каждый push в `main` и на pull request: `npm ci`,
`npm run typecheck`, `npm run build`, затем проверка, что собранный `dist/` совпадает с
коммитом (`git diff --exit-code -- dist`). Меняя что-то в `src/`, пересоберите и закоммитьте
`dist`, иначе CI отклонит ветку.

## Релизы

Поднимите `version` в `package.json`, добавьте запись в `CHANGELOG.md`, поставьте тег `vX.Y.Z`
и запушьте его. `.github/workflows/release.yml` соберёт плагин, проверит, что тег равен
`v<version>` из `package.json`, упакует `opencode-subagent-dashboard-vX.Y.Z.zip` (`src`,
`dist`, документация и файлы сборки) и приложит архив к GitHub Release вместе со
сгенерированными заметками. Установка из архива описана в разделе
[«Установка из архива релиза»](#установка-из-архива-релиза).
