# Сабагенты для OpenCode Desktop

Плагин боковой панели OpenCode Desktop 2: показывает сабагентов текущей сессии деревом — кто
сейчас работает, чем занят и сколько уже потратил.

В строке: точка статуса, имя агента, заголовок сессии, токены (вход + выход), цена и
затраченное время. Клик по строке открывает сессию сабагента в новой вкладке. Пока сабагенты
работают, в нижней полосе окна виден бейдж `⚡ N`.

English: [README.md](README.md).

## Требования

- OpenCode Desktop 2.3.x. GUI-API плагинов экспериментальный и может меняться между
  релизами.
- Node.js 20+ — только если собираете плагин сами; в репозитории уже лежит собранный
  `dist/gui-experimental.cjs`.
- Плагин собран под `@opencode/plugin` 2.3.2, версия закреплена в `package.json`.

## Установка из git (рекомендуется)

```bash
git clone https://github.com/edwardgra4ev/opencode-subagent-dashboard \
  ~/.config/opencode/plugins/subagent-dashboard
```

Добавьте плагин в `~/.config/opencode/opencode.json`:

```json
{
  "plugins": ["./plugins/subagent-dashboard"]
}
```

Один раз перезапустите OpenCode Desktop. Панель появится в меню `+` боковой области, в
палитре команд и по `/agents`.

`dist/gui-experimental.cjs` лежит в репозитории, поэтому после клонирования собирать ничего
не нужно. Обновление:

```bash
git -C ~/.config/opencode/plugins/subagent-dashboard pull
```

Затем перезапустите Desktop (или перезагрузите плагины в приложении).

## Установка из другого каталога

Плагин грузится из любого каталога — укажите его путь в `plugins` (абсолютный или
относительно каталога конфигурации):

```json
{
  "plugins": ["/mnt/hdd/Dev/opencode-plugins/opencode-subagent-dashboard"]
}
```

## Как открыть панель

- Меню `+` боковой области, затем **Сабагенты**.
- Палитра команд, **Открыть сабагентов**.
- `/agents` в поле ввода. Без открытой сессии команда недоступна.
- Горячая клавиша: пункт меню `+` показывает сочетание команды `subagent-dashboard.open`.
  По умолчанию сочетания нет — назначьте его этой команде в Settings › Shortcuts.

## Что показывает панель

Панель перечисляет сабагентов сессии в текущей вкладке, а не всех сессий приложения.

**Дерево.** Строки группируются по `parentID` и сдвигаются по глубине, поэтому дети всегда
стоят под своим родителем. Если у строки на последнем уровне (3) есть свои дети, они
сворачиваются в некликабельную строку-маркер `…`.

**Порядок.** Внутри уровня сначала идут выполняющиеся строки, остальные — по времени создания,
новые сверху. Дети всегда стоят сразу под родителем, так что дерево читается сверху вниз.
Сабагент, о котором известно только из списка `background` сессии и которого ещё нет в сторе
сессий, показывается первым как выполняющийся, курсивом, пока не синхронизирован.

**Строка.** Точка статуса, агент, заголовок, токены (вход + выход), цена, время. Заголовок
обрезается до одной строки, полный текст виден по наведению. Статусы и цвет точки:

| Статус | Точка | Значение |
| --- | --- | --- |
| Выполняется | синяя | Ещё работает, надо подождать |
| Завершён успешно | зелёная | Закончил нормально |
| Ошибка | красная | Закончил с ошибкой |
| Прерван | оранжевая | Остановлен до завершения |
| Простаивает | серая | Известен, но не запущен или не работает |

**Пустой расход.** У ещё выполняющегося сабагента, от которого не пришло ни одного события
расхода, вместо нулей стоит `—` в токенах и цене. Суммы показываются как `812`, `12.3k`,
`1.2M`; цена меньше цента — `<$0.01`.

**Время.** У выполняющейся строки — от старта прогона (`time.busy`) до сейчас, обновляется раз
в секунду. У завершённой — длительность прогона, `idle − busy`. Если нужной отметки нет, `—`.

**Клик.** Строка открывает сессию этого сабагента в новой вкладке. Строки сессий, которых
больше нет (`missing`, например после удаления), приглушены и отключены.

**Фильтр.** **Только активные** скрывает завершённых сабагентов и группу завершённых.

**Группа завершённых.** Завершённые сабагенты лежат под заголовком `N завершено`, который
сворачивается кликом. По умолчанию группа раскрыта, если завершённых не больше 5, иначе
свёрнута.

**Длинные списки.** Одновременно рисуется не больше 200 строк; кнопка `+N ещё` показывает
остальные.

**Состояния.** `Сабагентов нет`, пока в сессии их нет; `Загрузка…`, пока идёт первая
синхронизация; `Нет активных сабагентов`, если фильтр ничего не оставил; тост, если
синхронизация не удалась.

**Футер.** `N сабагентов · X токенов · $Y` по всем сабагентам сессии, включая скрытых
фильтром, свёрнутой группой и лимитом строк.

**Бейдж.** Пока выполняется хотя бы один сабагент текущей сессии, в нижней полосе окна виден
`⚡ N`. Клик открывает панель.

**Уведомления.** Когда сабагент завершается, а ни одно окно приложения не в фокусе, приходит
системное уведомление: ошибки — как ошибки, остальные — как обычное завершение. Клик по
уведомлению открывает сессию этого сабагента. Уведомления подчиняются настройкам OpenCode
(Settings › Notifications: Agent и Errors, а также их звуки) и приходят не чаще одного раза на
завершение.

**Данные.** Всё берётся из стора сессий Desktop и его событий; собственного доступа к базе у
панели нет. При переходе на сессию её дети загружаются один раз, дальше статус, токены и
таймеры обновляются по событиям. Состояние панели (фильтр, раскрытые группы) сбрасывается при
смене сессии.

## Ограничения и заметки

- Показываются только сабагенты текущей сессии; сессии других вкладок — нет.
- Глубина дерева ограничена 3 уровнями; более глубокие сабагенты видны как `…`.
- До 200 строк рисуется сразу, остальные — по кнопке `+N ещё`.
- Плагин рассчитан на OpenCode Desktop 2.3.x и экспериментальный GUI-API плагинов; обновление
  Desktop может сломать панель до обновления плагина.
- Время выполняющейся строки всегда считается от `time.busy`: у возобновлённой сессии
  остаётся старый `time.idle`, и таймер по нему замер бы.

## Темы

Панель оформлена только переменными приложения `--v2-*`, поэтому светлая и тёмная темы,
включая свои, наследуются от Desktop.

## Разработка

```bash
npm install
npm run typecheck
npm run build     # пишет dist/gui-experimental.cjs, файл лежит в репозитории
npm run watch     # пересборка при изменении; панель перезагружается во всех окнах
```

`dist/` хранится в репозитории, чтобы обычный `git clone` не требовал сборки. Меняя `src/`,
пересоберите и закоммитьте `dist/gui-experimental.cjs` вместе с исходниками.

Структура:

| Путь | Назначение |
| --- | --- |
| `src/index.ts` | серверная половина: `Plugin.define({ id: "subagent-dashboard" })`, без обработчиков |
| `src/gui.tsx` | вход GUI: панель, пункт меню `+`, команда `/agents`, слот нижней полосы, стили |
| `src/gui/dashboard.tsx` | сама панель: строки, фильтр, группа завершённых, лимит строк, футер |
| `src/gui/badge.tsx` | бейдж `⚡ N` и уведомления о завершении |
| `src/gui/model.ts` | чистая модель: дерево, порядок, слияние с `background`, форматтеры |
| `src/gui/definition.ts` | декларация плагина со словарями en/ru |
| `src/gui/i18n.ts` | тексты на английском и русском |
